# codex-index-cam1753

This archived repository preserves the history of the Cambridge University Library
MS Add. 1753 indexing work. On 2026-09-04, Phase 3 of MAM-basics' index-trio
evacuation moved the live data and programs into
[`bdenckla/MAM-basics`](https://github.com/bdenckla/MAM-basics):

- [`cam1753/`](https://github.com/bdenckla/MAM-basics/tree/main/cam1753) holds the
  scans, annotations, reports, provenance, and procedures.
- [`py/`](https://github.com/bdenckla/MAM-basics/tree/main/py) holds the Cambridge
  1753 programs.
- [`MAM-XML/`](https://github.com/bdenckla/MAM-basics/tree/main/MAM-XML) is the
  shared pinned word-sequence snapshot.

The 14 source spreads are retained there. The 28 single-page JPEGs are regenerated
from those spreads when an editor or crop task needs them and are not tracked.
